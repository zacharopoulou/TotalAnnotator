# tmVar3 - local benchmark data

Only `test.jsonl` is committed to this repo. It is the held-out
evaluation split, used for testing annotators.

Regenerate the full corpus locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/tmvar3.py
```

That downloads the split from Hugging Face (`bigbio/tmvar_v3`,
config `tmvar_v3_bigbio_kb`) into this directory.

tmVar3 annotates genetic variant mentions with dbSNP / ClinGen Allele Registry normalization.

tmVar3 ships as a single test set (no train/validation).

`TMVAR3_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/tmvar3_analytics.py` from a full local download and
documents the entire corpus shape (counts, entity types, normalization
coverage), even though only test.jsonl lives here.
