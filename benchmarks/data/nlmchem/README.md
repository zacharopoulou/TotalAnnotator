# NLM-Chem - local benchmark data

Only `test.jsonl` is committed to this repo. It is the held-out
evaluation split, used for testing annotators.

The other split(s) (train, validation) are intentionally **not** shipped here (see `.gitignore`). Regenerate the full corpus locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/nlmchem.py
```

That downloads all splits from Hugging Face (`bigbio/nlmchem`,
config `nlmchem_bigbio_kb`) into this directory.

NLM-Chem annotates chemical mentions with MeSH normalization (150 full-text articles).

`NLMCHEM_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/nlmchem_analytics.py` from a full local download and
documents the entire corpus shape (counts, entity types, normalization
coverage), even though only test.jsonl lives here.
