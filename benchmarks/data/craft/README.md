# CRAFT - local benchmark data

Only `test.jsonl` is committed to this repo. It is the held-out
evaluation split, used for testing annotators.

The other split(s) (train, validation) are intentionally **not** shipped here (see `.gitignore`). Regenerate the full corpus locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/craft.py
```

That downloads all splits from Hugging Face (`bigbio/craft`,
config `craft_bigbio_kb`) into this directory.

CRAFT annotates CRAFT concept annotations across multiple ontologies (ChEBI, CL, GO, NCBITaxon, PR, SO).

`CRAFT_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/craft_analytics.py` from a full local download and
documents the entire corpus shape (counts, entity types, normalization
coverage), even though only test.jsonl lives here.
