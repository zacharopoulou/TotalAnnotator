# MACCROBAT - local benchmark data

Only `test.jsonl` is committed to this repo. MACCROBAT ships as a single set of
200 clinical case reports (there is no official train/test split), so the whole
corpus is used as the evaluation set.

MACCROBAT is **not** part of BigBIO. It is pulled from the Hugging Face dataset
`singh-aditya/MACCROBAT_biomedical_ner` and converted into the same bigbio_kb
shape the other benchmarks use, so the shared analytics runs unchanged.
Regenerate locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/maccrobat.py
```

MACCROBAT annotates a large set of fine-grained clinical entity types (AGE, SEX,
HISTORY, SIGN_SYMPTOM, DIAGNOSTIC_PROCEDURE, MEDICATION, LAB_VALUE, and many
more); spans carry char offsets but no knowledge-base normalization.

`MACCROBAT_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/maccrobat_analytics.py` and documents the corpus shape
(counts, entity types, span lengths, top mentions).
