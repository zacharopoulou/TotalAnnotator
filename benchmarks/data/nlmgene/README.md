# NLM-Gene - local benchmark data

Only `test.jsonl` is committed to this repo. It is the held-out
evaluation split, used for testing annotators.

The other split(s) (train) are intentionally **not** shipped here (see `.gitignore`). Regenerate the full corpus locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/nlmgene.py
```

That downloads all splits from Hugging Face (`bigbio/nlm_gene`,
config `nlm_gene_bigbio_kb`) into this directory.

NLM-Gene annotates gene/protein mentions with NCBI Gene normalization.

NLM-Gene has no validation split.

`NLMGENE_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/nlmgene_analytics.py` from a full local download and
documents the entire corpus shape (counts, entity types, normalization
coverage), even though only test.jsonl lives here.
