# BC5CDR - local benchmark data

Only `test.jsonl` is committed to this repo. It is the official held-out
evaluation split, used for testing annotators.

`train.jsonl` and `validation.jsonl` are intentionally **not** shipped here
(see `.gitignore`). Anyone who needs them can regenerate the full corpus
locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/bc5cdr.py
```

That downloads all three splits from Hugging Face (`bigbio/bc5cdr`,
config `bc5cdr_bigbio_kb`) into this directory.

BC5CDR has two entity types (Chemical, Disease) with MeSH normalization,
and one relation type (CID = Chemical-Induced-Disease).

`BC5CDR_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/bc5cdr_analytics.py` from a full local download and
documents the entire corpus shape (counts, entity types, normalization
coverage, relations), even though only the test split lives here.
