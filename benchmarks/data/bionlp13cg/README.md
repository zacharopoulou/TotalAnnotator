# BioNLP13CG - local benchmark data

Only `test.jsonl` is committed to this repo. It is the held-out
evaluation split, used for testing annotators.

The other split(s) (train, validation) are intentionally **not** shipped here (see `.gitignore`). Regenerate the full corpus locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/bionlp13cg.py
```

That downloads all splits from Hugging Face (`bigbio/bionlp_st_2013_cg`,
config `bionlp_st_2013_cg_bigbio_kb`) into this directory.

BioNLP13CG annotates 16 cancer-genetics entity types (BioNLP 2013 Cancer Genetics task); no normalization.

`BIONLP13CG_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/bionlp13cg_analytics.py` from a full local download and
documents the entire corpus shape (counts, entity types, normalization
coverage), even though only test.jsonl lives here.
