# GNormPlus - local benchmark data

Only `test.jsonl` is committed to this repo. It is the official held-out
evaluation split, used for testing annotators.

`train.jsonl` is intentionally **not** shipped here (see `.gitignore`).
GNormPlus does not have a separate validation split.
Anyone who needs the train split can regenerate the full corpus locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/gnormplus.py
```

That downloads both splits from Hugging Face (`bigbio/gnormplus`,
config `gnormplus_bigbio_kb`) into this directory.

GNormPlus has three entity types (Gene, FamilyName, DomainMotif) with
NCBI Gene normalization on gene mentions. No relations.

Note: GNormPlus does not distinguish gene from protein mentions. Both
are labeled `Gene` and normalized to the same NCBI Gene ID, because the
corpus was built to evaluate gene normalization, not protein-specific
recognition.

`GNORMPLUS_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/gnormplus_analytics.py` from a full local download
and documents the entire corpus shape (counts, entity types, normalization
coverage, top mentions), even though only the test split lives here.
