# BioRED - local benchmark data

Only `test.jsonl` is committed to this repo. It is the held-out
evaluation split, used for testing annotators.

The other split(s) (train, validation) are intentionally **not** shipped here (see `.gitignore`). Regenerate the full corpus locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/biored.py
```

That downloads all splits from Hugging Face (`bigbio/biored`,
config `biored_bigbio_kb`) into this directory.

BioRED annotates genes, diseases, chemicals, species, variants and cell lines with normalization, plus relations.

`BIORED_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/biored_analytics.py` from a full local download and
documents the entire corpus shape (counts, entity types, normalization
coverage), even though only test.jsonl lives here.
