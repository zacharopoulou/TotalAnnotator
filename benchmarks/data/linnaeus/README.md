# Linnaeus - local benchmark data

Only `train.jsonl` is committed to this repo. It is the held-out
evaluation split, used for testing annotators.

Regenerate the full corpus locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/linnaeus.py
```

That downloads the split from Hugging Face (`bigbio/linnaeus`,
config `linnaeus_bigbio_kb`) into this directory.

Linnaeus annotates species mentions with NCBI Taxonomy normalization.

Linnaeus ships as a single split (train) in bigbio_kb; used as the eval set.

`LINNAEUS_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/linnaeus_analytics.py` from a full local download and
documents the entire corpus shape (counts, entity types, normalization
coverage), even though only train.jsonl lives here.
