# BC4CHEMD - local benchmark data

Only `test.jsonl` is committed to this repo. It is the held-out
evaluation split, used for testing annotators.

The other split(s) (train, validation) are intentionally **not** shipped here (see `.gitignore`). Regenerate the full corpus locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/bc4chemd.py
```

That downloads all splits from Hugging Face (`bigbio/chemdner`,
config `chemdner_bigbio_kb`) into this directory.

BC4CHEMD annotates chemical mentions (BioCreative IV CHEMDNER); no normalization.

BC4CHEMD is the BioCreative IV CHEMDNER corpus (bigbio/chemdner).

`BC4CHEMD_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/bc4chemd_analytics.py` from a full local download and
documents the entire corpus shape (counts, entity types, normalization
coverage), even though only test.jsonl lives here.
