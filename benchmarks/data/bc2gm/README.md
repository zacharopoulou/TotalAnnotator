# BC2GM - local benchmark data

Only `test.jsonl` is committed to this repo. It is the official held-out
evaluation split, used for testing annotators.

`train.jsonl` and `validation.jsonl` are intentionally **not** shipped
here (see `.gitignore`). Anyone who needs them can regenerate the full
corpus locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/bc2gm.py
```

That downloads all three splits from Hugging Face
(`spyysalo/bc2gm_corpus`, a community mirror of the BioCreative II Gene
Mention task) into this directory.

BC2GM is **sentence-level**, not document-level, and ships in **IOB
token format** rather than `bigbio_kb`:

- each row contains `tokens` (list of words) and `ner_tags` (parallel
  list of `O`, `B-GENE`, `I-GENE` labels)
- one entity type only: gene mentions
- no character offsets, no normalization IDs, no relations

`BC2GM_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/bc2gm_analytics.py`, which walks the IOB tag
sequences to reconstruct gene mentions and reports counts and length
statistics per split.
