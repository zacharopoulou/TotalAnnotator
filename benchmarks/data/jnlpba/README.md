# JNLPBA - local benchmark data

Only `validation.jsonl` is committed to this repo. It is the held-out
evaluation split, used for testing annotators.

The other split(s) (train) are intentionally **not** shipped here (see `.gitignore`). Regenerate the full corpus locally:

```
uv sync --extra benchmarks
uv run python benchmarks/scripts/jnlpba.py
```

That downloads all splits from Hugging Face (`bigbio/jnlpba`,
config `jnlpba_bigbio_kb`) into this directory.

JNLPBA annotates five molecular-biology types (protein, DNA, RNA, cell line, cell type); no normalization.

JNLPBA has no test split; validation is the held-out set.

`JNLPBA_ANALYTICS_SUMMARY.md` is generated by
`benchmarks/analytics/jnlpba_analytics.py` from a full local download and
documents the entire corpus shape (counts, entity types, normalization
coverage), even though only validation.jsonl lives here.
